## 📌 1. Project Overview

**AnimeEdu** is an AI-powered personalized learning platform designed to make education more interactive, engaging, and accessible through animated explanations and intelligent learning assistance.

The platform combines Artificial Intelligence (AI), Machine Learning (ML), Natural Language Processing (NLP), and Generative AI to transform complex educational concepts into simplified, visually engaging learning experiences.

Learners can explore educational topics, select their preferred explanation style and language, and learn through animated teacher or anime-style characters. The platform also provides an intelligent doubt-solving assistant, interactive quizzes, personalized learning recommendations, and performance tracking.

AnimeEdu aims to bridge the gap between traditional learning methods and modern AI-driven education by providing an adaptive learning environment that considers individual learning preferences and progress.

## 🎯 2. Problem Statement

Traditional educational platforms primarily depend on text-based materials, static presentations, and conventional video lectures. These approaches may not effectively accommodate different learning preferences, particularly when students struggle to understand complex concepts.

Some common challenges include:

- Difficulty understanding complicated academic topics.
- Limited personalization in traditional learning resources.
- Lack of interactive and engaging educational content.
- Delayed assistance when students encounter doubts.
- Limited mechanisms for tracking individual learning progress.
- Reduced engagement during lengthy learning sessions.

There is a need for an intelligent educational platform that simplifies complex topics, provides personalized explanations, and encourages active student participation.

## 💡 3. Proposed Solution

AnimeEdu introduces an AI-driven educational environment that combines personalized explanations, animated learning, conversational AI, and interactive assessments.

The proposed system allows students to:

- Search for any supported educational topic.
- Select a preferred language and explanation style.
- Receive simplified, AI-generated educational explanations.
- Learn through animated or character-based presentations.
- Interact with an AI-powered doubt-solving assistant.
- Attempt topic-based quizzes and learning activities.
- Monitor academic performance through a personalized dashboard.

By integrating these capabilities, AnimeEdu aims to make learning more understandable, interactive, and student-centered.

8. **Performance Analysis:** Learning results are recorded for progress monitoring.

## ⚙️ 10. Installation and Setup

### Prerequisites

Ensure that the following tools are installed:

- Python 3.10 or a compatible supported version.
- Node.js and npm (if using React).
- Git.
- Visual Studio Code or another code editor.
- Required AI model/API credentials, if applicable.

### Step 1: Clone the Repository

```bash
git clone https://github.com/spandana-200514/Anime-Edu.git
```

### Step 2: Navigate to the Project

```bash
cd Anime-Edu
```

### Step 3: Create a Virtual Environment

```bash
python -m venv venv
```

Activate the environment:

**Windows:**
```bash
venv\Scripts\activate
```

**Linux / macOS:**
```bash
source venv/bin/activate
```

### Step 4: Install Python Dependencies

```bash
pip install -r requirements.txt
```

### Step 5: Configure Environment Variables

Create a `.env` file and configure the required API credentials.

Example:

```env
LLM_API_KEY=your_api_key
MODEL_NAME=your_model_name
```

Never upload actual API keys, passwords, or sensitive credentials to GitHub.

### Step 6: Run the Application

For a FastAPI backend:

```bash
uvicorn backend.main:app --reload
```

For a React frontend:

```bash
cd frontend
npm install
npm start
```

For a Streamlit interface, if configured:

```bash
streamlit run app.py
```

The actual commands may vary depending on the final project structure and entry-point files.
